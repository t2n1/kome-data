# Từ điển Nhật-Việt — KOME Data Pipeline

Mở rộng phần từ điển từ `CLAUDE.md`, mỗi thuật ngữ thêm cột "xuất hiện ở file OBC nào".

| Thuật ngữ Nhật | Nghĩa tiếng Việt | Xuất hiện ở file OBC |
|---|---|---|
| 得意先 | Khách hàng | 得意先全情報 · 売上伝票データ · 直送先 · 入金伝票データ · 得意先元帳 |
| 請求先 | Bên nhận hoá đơn (có thể khác 得意先) | 売上伝票データ · 請求先元帳 |
| 伝票 | Phiếu | 売上伝票データ · 入金伝票データ |
| 赤伝 | Phiếu đỏ (hàng trả lại, số ÂM, không được lọc bỏ) | 売上伝票データ |
| 粗利益 | Lãi gộp | 売上伝票データ (tính toán) |
| 単価 | Đơn giá | 取引単価データ · 売上伝票データ |
| 単位原価 | Giá vốn đơn vị | 商品データ · 取引単価データ |
| 締め日 | Ngày chốt công nợ | 得意先全情報 |
| 直送先 | Điểm giao thẳng | 直送先 · 売上伝票データ |
| 担当者 | Người phụ trách khách | 得意先全情報 · 売上伝票データ · 入金伝票データ |
| 倉庫 | Kho | 在庫一覧 |
| 賞味期限 | Hạn sử dụng | 商品データ |
| 荷姿区分 | Quy cách đóng gói (00 = バラ lẻ, 02 = ケース thùng) | 商品データ · 取引単価データ · 売上伝票データ · 在庫一覧 |
| 商品 | Sản phẩm / Mã hàng | 商品データ · 売上伝票データ · 取引単価データ · 在庫一覧 |
| 売上 | Doanh số bán hàng | 売上伝票データ · 売上明細表 · 得意先元帳 |
| 入金 | Tiền thu vào | 入金伝票データ |
| 仕入先 | Nhà cung cấp | 仕入先 |
